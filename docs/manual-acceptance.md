# 真实 Codex 手工验收

这份检查需要用户主动选择合适时间，不由自动化关闭当前会话。

1. 记下 Windows 原有时区，保存 Codex 中的工作，确认没有不希望中断的任务。
2. 从用户界面正常退出 Codex。不要因为本工具测试而结束研究/训练进程或强杀后台。
3. 运行启动器，选择自动建议或手动 IANA 时区，检查目标时间与客户端路径。
4. 若提示仍有实例或身份/权限无法确认，请处理提示或停止测试，不修改 WindowsApps 权限。
5. 点击“保存并启动”。记录启动器版本、Windows 版本、Codex 版本/安装渠道。
6. 若 Codex 允许使用开发者工具，可人工只读查看：

```javascript
Intl.DateTimeFormat().resolvedOptions().timeZone
new Date().getTimezoneOffset()
```

7. 记录真实返回值；无入口或无法确认就写“未验证”，不要用聊天回答代替。
8. 独立打开一个应用并检查 Windows 时区仍为原值。不要期待 Codex 后代不继承 TZ。
9. 若运行中切换代理节点，本工具不热切换/重启 Codex；下次正常退出后重新检测并启动。
