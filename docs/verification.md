### 测试覆盖

- IANA 有效性、国家/Windows 名/固定偏移拒绝、夏令时冬夏偏移、原子配置与损坏恢复。
- 公网 IPv4/IPv6 与特殊地址拒绝；trace 重复字段、异常 JSON、回显 IP 不符、超大响应。
- 403/404/429/500、重定向、流式响应上限、包含慢响应体的超时、取消与旧结果作废。
- 明确目标出口 B 被传给定位服务；重复/辅助/不同地址族出口冲突时不自动建议。
- 目的地址代理选择、PAC 明确错误不退回直连、SOCKS-only/代理凭据拒绝。
- 桌面身份与 CLI 区分、手动路径不能绕过验证、空/多个候选不盲选。
- 跨 Store/普通安装/不同路径/旧版本运行保护；权限或包身份不明时安全阻止。
- 匹配 Codex/OpenAI 元数据但资源缺失或运行后被移除时返回 Uncertain，而非 Clear。
- 只给新子进程设置 TZ，移除继承的 ELECTRON_RUN_AS_NODE，不重写全局环境。
- 启动关键区间内正常关闭被暂时阻止，直到完成安全启动/失败清理；异常后恢复关闭、拒绝重复进入，检测阶段仍可取消。

## 真实网络：不只保留成功案例

这些记录来自开发期间的显式匿名诊断，未启动 Codex，也没有令牌、Cookie、原始
IP、代理地址/口令、客户端完整路径或原始响应体。

- [一致观测](evidence/launcher-network-consistent.json)：3 次 IPv4 观测一致，明确 IP
  定位得到有效的 `America/Los_Angeles` 建议。
- [冲突观测](evidence/launcher-network-conflict.json)：3 次观测存在矛盾，
  `conflicting_egress`、Suggested=false，正确转为手动处理。
- [早期试打包诊断](evidence/packaged-network-consistent.json)：当时的试打包 EXE
  能完成相同匿名请求。它**不是最终冻结二进制再次联网的证明**。

诊断外层的 success 表示“诊断完成并生成报告”，不等于网络检测成功、客户端已启动
或时区已生效。以其中 network.Suggested/Code 判断网络结论。

代理规则按域名、进程或 IPv4/IPv6 分流时，启动器请求可能与 Codex 不同；服务节点
切换也会改变观测。程序不修改用户规则来强行得到一致结果，不用通用 IP 查询冒充
Codex 的真实出口，不绕过 HTTPS 验证。手动选择始终可用。

Self-contained 是打包配置与本机 EXE 自检的事实；没有在“完全不安装 .NET”的干净
虚拟机再测，不能据此扩大兼容性承诺。单文件可能解包运行时；开发环境将缓存/临时
文件定向到本仓库，但这不意味着用户运行时零落盘。

完整步骤见 [manual-acceptance.md](manual-acceptance.md)。不要用询问模型“现在几点”

组件可能仍使用原环境。
